# 🚀 Muhammed Shaahidh — Portfolio

A modern, immersive **3D digital portfolio** showcasing my skills, experience, and projects in **DevOps**, **Cloud Engineering**, and **Network Engineering**.

---

## ✨ Features

- 🎮 **Three.js 3D Animated Background** — floating particles, wireframe geometric shapes, and mouse-reactive camera
- 💎 **Glassmorphism UI** — frosted glass cards with gradient borders and glow effects
- 🌊 **Scroll-triggered animations** — staggered reveals and smooth transitions
- 🖥️ **Terminal-style about card** — interactive developer terminal aesthetic
- 📱 **Fully responsive** — optimized for desktop, tablet, and mobile
- 🔗 **Smooth scroll navigation** with active section tracking
- 📄 **CV download** — latest resume available for download

---

## 🛠️ Tech Stack

| Feature | Technology |
|---------|-----------|
| 3D Background | Three.js (r128) |
| Layout & Styling | CSS3 (Grid, Flexbox, Custom Properties) |
| Typography | Inter + JetBrains Mono (Google Fonts) |
| Animations | CSS transitions + Intersection Observer API |
| Structure | Semantic HTML5 |

---

## 📂 Sections

- **Hero** — Introduction with 3D background, profile card, and quick stats
- **About** — Professional summary, terminal card, education & certifications
- **Experience** — SLT Mobitel internship with detailed bullet points
- **Projects** — 6 featured projects with tech stacks and GitHub links
- **Skills** — Categorized technical skills (Linux, DevOps, Networking, Programming, Databases, Soft Skills)
- **Contact** — Contact information and message form
